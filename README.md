# Functional Treat

A Python menu-driven program that demonstrates the use of **functions**, **recursion**, **lambda functions**, **built-in functions**, **sorting**, and **multiple return values** by performing operations on **1D and 2D arrays**.

## 📌 Features

- ✅ Input Data (1D Array or 2D Array)
- ✅ Display Data Summary
- ✅ Calculate Factorial using Recursion
- ✅ Filter Data using Lambda Function
- ✅ Sort Data (Ascending / Descending)
- ✅ Display Dataset Statistics
- ✅ Menu-Driven Interface

## 🛠 Concepts Used

- Functions
- Recursion
- Lambda Function
- Built-in Functions
- List Operations
- Conditional Statements
- Loops
- Multiple Return Values
- 1D & 2D Arrays

## 📖 Function Description

### 1. Welcome Function
Displays the welcome message when the program starts.

### 2. Menu Function
Displays the main menu repeatedly until the user exits.

### 3. Input Data
Allows the user to enter either:
- 1D Array
- 2D Array

### 4. Display Summary
Shows:
- Total Elements
- Minimum Value
- Maximum Value
- Sum
- Average

### 5. Factorial
Calculates the factorial of a number using **Recursion**.

### 6. Filter Data
Filters elements greater than or equal to the given threshold using a **Lambda Function**.

### 7. Sort Data
Sorts the dataset in:
- Ascending Order
- Descending Order

### 8. Dataset Statistics
Returns:
- Minimum
- Maximum
- Sum
- Average

using **Multiple Return Values**.
